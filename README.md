# Download Speed Test

Консольный скрипт на Node.js, который измеряет скорость скачивания по указанному адресу.

Скрипт:
1. принимает URL (например, тяжёлую картинку или файл);
2. делает к нему **10 последовательных запросов**, каждый раз дожидаясь полного получения тела ответа;
3. считает **среднее время запроса** и **общий объём скачанных данных**;
4. печатает **скорость скачивания**.

## Требования

- Node.js **18+** (используется встроенный `fetch`, внешних зависимостей нет)

## Запуск

```bash
git clone https://github.com/Korrusx/TestTask.git
cd TestTask
node speedtest.js https://proof.ovh.net/files/10Mb.dat
```

или через npm:

```bash
npm start -- https://proof.ovh.net/files/10Mb.dat
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Время запроса | миллисекунды (**ms**) |
| Объём данных | байты с двоичными приставками: 1 KiB = 1024 B, 1 MiB = 1024 KiB |
| Скорость (основная) | **MiB/s** — мебибайты в секунду, 1 MiB = 1 048 576 байт |
| Скорость (дополнительно) | **Mbit/s** — мегабиты в секунду, 1 Mbit = 1 000 000 бит (как у провайдеров) |

## Как считается

- **Время запроса** — от начала запроса до получения последнего байта тела ответа
  (замер через `process.hrtime`).
- **Среднее время** — сумма времени всех 10 запросов / 10.
- **Общий объём** — сумма байтов тела всех ответов. При HTTP-сжатии `fetch` распаковывает тело, поэтому в расчёт идёт объём после распаковки.
- **Скорость** — общий объём / суммарное время всех запросов. Это скорость скачивания с выбранного URL с учётом ожидания ответа сервера.

На каждый запрос отводится 30 секунд, включая чтение тела ответа. При превышении таймаута, сетевой ошибке или HTTP-статусе вне диапазона 2xx скрипт выводит ошибку и завершается с кодом 1.
