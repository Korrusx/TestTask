# Download Speed Test

Консольный скрипт на Node.js, который измеряет скорость скачивания по указанному адресу.

Скрипт:
1. принимает URL (например, тяжёлую картинку или файл);
2. делает к нему **10 последовательных запросов**, каждый раз дожидаясь полного получения тела ответа;
3. считает **среднее время запроса** и **общий объём скачанных данных**;
4. печатает **скорость скачивания**.

## Требования

- Node.js **18+** (используется встроенный `fetch`, внешних зависимостей нет)

## Запуск

```bash
git clone <repo-url>
cd <repo-dir>
node speedtest.js <url>
```

или через npm:

```bash
npm start -- <url>
```

### Пример

```bash
node speedtest.js https://proof.ovh.net/files/10Mb.dat
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Время запроса | миллисекунды (**ms**) |
| Объём данных | байты с двоичными приставками: 1 KB = 1024 B, 1 MB = 1024 KB |
| Скорость (основная) | **MB/s** — мегабайты в секунду, 1 MB = 1 048 576 байт |
| Скорость (дополнительно) | **Mbit/s** — мегабиты в секунду, 1 Mbit = 1 000 000 бит (как у провайдеров) |

## Как считается

- **Время запроса** — от момента отправки запроса до получения последнего байта тела ответа
  (замер через `process.hrtime`).
- **Среднее время** — сумма времени всех 10 запросов / 10.
- **Общий объём** — сумма реально полученных байт тела ответа по всем запросам.
- **Скорость** — общий объём / суммарное время всех запросов.

Если какой-либо запрос завершается ошибкой (сеть или HTTP-статус не 2xx), скрипт выводит ошибку и завершается с кодом 1.
